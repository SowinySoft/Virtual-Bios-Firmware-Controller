%--- Abstract ------------------------------------------------------------------
\begin{abstract}
The \ac{BIOS} firmware constitutes the most privileged software layer in any x86 system, yet consumers, security researchers, and system integrators possess limited means to inspect, modify, or extend it without resorting to expensive dedicated hardware programmers. This paper presents the \acf{vbfc} (\vbfc): an open-source, low-cost \ac{SPI} interposer that sits transparently between a motherboard's chipset (\ac{PCH}) and its \ac{SPI} flash chip, enabling real-time, selective byte substitution of firmware images during boot. Built around the \rp (\SI{264}{KB} \ac{SRAM}, \SI{2}{MB} flash) and a \SI{16}{MB} extension flash (\wq), the \vbfc implements four core capabilities: (1) a cryptographic signing layer based on \ac{HMAC}-\ac{SHA}256 that prevents unauthorized image injection and provides anti-rollback guarantees; (2) an address translation map (shadow map) for transparent region remapping between the original and extension flash; (3) an in-flight byte-patching engine that applies per-byte substitutions in the \ac{SPI} arbiter's hot path with \SI{<1}{\micro s} latency; and (4) a passive \ac{SPI} bus transaction sniffer for forensic analysis and verification. We describe the complete system architecture, the \ac{SPI} arbiter state machine, the signed-image header format, the shadow map data structure, and the host-side provisioning toolchain. Experimental evaluation on physical hardware demonstrates successful patching of \ac{UEFI} firmware volumes, hidden \ac{BIOS} menu unlocking, and \ac{ME} region neutralization, with zero detectable boot-time overhead. The \vbfc hardware design, firmware, and host software are released under the MIT license to foster transparent firmware security research. This paper also includes a comprehensive real-hardware test phase procedure for validation on a Gigabyte G41 motherboard.
\end{abstract}
