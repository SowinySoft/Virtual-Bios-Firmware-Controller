# FPGA Tier (Planned)

Future ECP5-based implementation for quad-SPI and full-image dev emulate mode.

Shares the same shadow map format (`docs/shadow-map-spec.md`) and USB protocol
as the RP2040 MVP.

Target boards: ULX3S, Tang Nano 20K.

See [SPI Spy](https://github.com/osresearch/spispy) for reference timing architecture.
